# G-Menu 显示器型号

## 1. 数据来源与用途

本表整理自 G-Menu 3.38.0 的 `app.asar` 配置数据。源文件 SHA-256 为：

```text
f6fae2c2889914cee56f391c1be545bc6c86b28b8edbdb81a1ce6148deab2830
```

配置版本为 47，共包含 326 条型号记录。型号表用于 G-Menu 的功能展示和界面命名。当前程序依据显示器响应和运行时探测结果判断 DDC/CI 实际能力。

## 2. 字段含义

| 字段 | 含义 |
|---|---|
| `Name` | 配置中使用的 EDID 型号名称 |
| `SupUsbDDC` | 配置声明的 USB 上行透传 DDC/CI 能力；该字段仅保存在配置中 |
| `SupOTA` | 配置是否声明支持固件在线升级 |
| `UIType` | Gamma 和 OverDrive 的界面名称类型 |

`UIType` 控制界面显示名称，DDC/CI 写入值由功能定义决定。类型 1 使用类型 0 的命名方式。

| 功能 | 类型 0 和类型 1 | 类型 2 |
|---|---|---|
| OverDrive | `Off`、`Weak`、`Medium`、`Strong`、`Boost` | `OD_Normal`、`Fast`、`Faster`、`Fastest`、`Extreme` |
| Gamma | `Gamma1`、`Gamma2`、`Gamma3`、`Gamma4`、`Gamma5`、`sRGB` | `2.2`、`2.0`、`2.4`、`1.8`、`2.6`、`sRGB` |

## 3. 型号名称归一化

G-Menu 查询配置前会依次执行以下处理：

1. 去除首尾的 Unicode 空白。
2. 名称以 `AOC` 开头时去除前三个字符。
3. 按空格分段并取最后一段。
4. 再按下划线分段并取最后一段。

因此，`Q27G4_D` 会归一化为 `D`，`Q27G4_WS` 和 `Q27G40ZE_WS` 都会归一化为 `WS`。后两条记录的字段值相同，覆盖后保持现有行为。差异化配置应使用归一化后唯一的型号键。

`EdidToFactory` 另包含一项型号映射：`AG493US3R4` 对应工厂型号 `AG493UCX2`。
